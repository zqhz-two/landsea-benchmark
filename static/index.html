使用教程

1. 复制考题：点击上方“复制全文”，发给任意大语言模型。

2. 运行代码：在本地执行模型交付的 Python 脚本，得到 90×180 判断矩阵 CSV 和黑白 PNG。

3. 拖入评分：把 CSV、180×90 PNG 或 1440×720 PNG 任一文件拖入右上方，立即给出得分和逐格对错图。

• 真值：Natural Earth 10m 海陆数据（v5.1.1）在 16,200 个格心采样；湖泊与里海算陆地，南极冰架算水域。

• 评分：海陆相关 MCC 40 + 容错 IoU 20 + 海岸线 F1 20 + 陆块识别 20，均按纬度余弦加权。

• PNG 只能有纯黑、纯白像素；1440×720 必须是 8 倍最近邻放大，否则拒收。
